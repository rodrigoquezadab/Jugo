# Dilema del Prisionero Iterado Evolutivo 2D (ASCII Retro)

Simulador interactivo espacial de Teoría de Juegos y Autómatas Celulares en un espacio toroidal, diseñado con estética Dwarf Fortress / terminal CRT.

## Modos de Juego
1. **🧪 Modo Laboratorio / Sandbox:** Simulación continua, control de parámetros en tiempo real, presets históricos y edición de cuadrícula.
2. **⚔️ Modo Duelo Multijugador por Turnos:** Juego táctico local (2 a 4 jugadores) con Puntos de Acción (PA), facciones, pulsos de caos y batalla evolutiva.

## Cómo Ejecutar
Abre `index.html` en cualquier navegador web moderno. No requiere instalación de dependencias.

## Control de Versiones con Tig y Git
El proyecto está versionado con Git. Puedes utilizar `tig` en tu terminal para navegar por los commits y cambios de forma interactiva en modo texto:

```bash
tig
```
Para ver el contexto técnico y formalización matemática detallada, consulta [`CONTEXT.md`](./CONTEXT.md).
